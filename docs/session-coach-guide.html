Task 02

Run the first setup audit

Setup auditP1
CLAUDE.mdsettings.jsonSkills · MCP
Add a PreToolUse guard hookEvidence · change · effectApply · Skip
1 2 3

  1. Start any session

    The audit runs 8 seconds in. No prompt needed.

    what it reads
    Your CLAUDE.md files, both settings.json files (environment variable names, never values), your skills, agents, plugins and MCP server names, and the names of stack files such as dbt_project.yml, snowflake.yml and .github/workflows.

  2. Read the cards

    Sorted P1 first, judged for your Snowflake, Azure and GitHub stack.

  3. Apply or skip

    Apply fills your prompt box. Review, then Enter.

Rerun

/coach setup refresh audits now.

  1. Check Now

    The judge's verdict after each turn, plus the next prompt.

  2. Watch the verdict

    on track drifting stuck blocked

  3. Work the list

    Recommendations, most important first.

  4. Scan vitals and score

    Plan usage, cache, context runway, git.

    the five score parts
    Context, Verification, Discipline, Leverage and Efficiency, 20 points each. They reward prompts that name files and done criteria, tests after edits, reading before editing, subagents and plan mode, and few failed or repeated commands.

Ground rules

Do and don't

Do

  • Fix P1 cards first
  • Review Apply before Enter
  • Set your profile once
  • Follow the fix timing

Don't

  • Ignore a stuck verdict
  • Apply cards unread
  • Steer mid-turn on Stop first
  • Skip P1 safety cards

Troubleshooting

When something looks wrong

The pane didn't open
Run /coach. If openPane is set to command, the pane opens only from /coach or the band's Details button.
Copy did nothing in the desktop app
Plugins can't write to the desktop clipboard. Copy puts the text in your prompt box instead, and Copy report saves to ~/.claude/session-coach/export.md.
No toasts appear
The desktop app doesn't show toasts. Results show in the status line at the top of the pane.
Does it cost tokens?
Yes. The judge (Haiku) runs every turn and analysis (Sonnet) every 3 turns, through your own session and plan. The Coach cost vital shows its share.
What leaves my machine?
Only the feed fetches. Model calls go through your own Claude Code session, with prompt excerpts capped at 280 characters and secret-looking values masked.
I changed the plugin and nothing happened
Run /reload-plugins or start a new session.
